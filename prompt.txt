# VISUAL DIRECTION

Build a coherent design system.

### Typography

Use a modern, highly readable font pairing.

Create strong hierarchy between:

* Eyebrow text
* Headlines
* Section headings
* Body copy
* Metadata
* Buttons

Large typography is welcome, but don't make everything enormous.

### Color

Use a restrained palette.

Prefer:

* Near-black / charcoal
* White / off-white
* One carefully selected accent color

The accent should feel technological without becoming stereotypically "cyberpunk."

Do not use many competing accent colors.

### Layout

Use:

* Generous whitespace
* Strong alignment
* Consistent max-widths
* Intentional asymmetry where useful
* Clear visual rhythm
* Interesting section transitions

Don't make every section look like:

heading → paragraph → 3 cards → heading → paragraph → 3 cards.

Create visual variety.
